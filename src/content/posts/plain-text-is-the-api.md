---

Every proprietary format is a bet that a company outlives your interest in the data.
Plain text bets on nothing.

> The best export button is the one you never need.

Markdown for prose, CSV for tables, JSON when structure matters:

```json
{ "format": "plain", "lock_in": false }
```
